# ΕΡΓΑΣΙΑ 08:Πρόβλεψη Χρήσης Πόρων Στο Alibaba Cluster Dataset

H εργασία αποσκοπεί στην πρόβλεψη της χρήσης πόρων σε Bare metal nodes, χρησιμοποιώντας time series data από CPU και RAM. Σκοπός της παρόν εργασίας είναι η κατασκευή, η εκπαίδευση και ο έλεγχος (testing) μοντέλων πρόβλεψης για χρονοσειρές τόσο για μικρά όσο και μεγάλα διαστήματά (short-term, long-term prediction).
