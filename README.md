# ΕΡΓΑΣΙΑ 08:Πρόβλεψη Χρήσης Πόρων Στο Alibaba Cluster Dataset

Σκοπός της εργασίας
Η παρούσα εργασία επικεντρώνεται στην πρόβλεψη της χρήσης υπολογιστικών πόρων σε bare metal nodes, αξιοποιώντας δεδομένα χρονοσειρών από CPU και RAM.Στόχος είναι η ανάπτυξη και αξιολόγηση μοντέλων βαθιάς μάθησης που μπορούν να προβλέψουν με ακρίβεια τη μελλοντική χρήση πόρων, τόσο σε βραχυπρόθεσμο όσο και σε μακροπρόθεσμο horizon (αριθμός μελλοντικών timesteps που πρέπει να προβλεφθούν).Μέσα από αυτή τη διαδικασία επιδιώκεται η αποτελεσματικότερη διαχείριση πόρων σε σύγχρονα τηλεπικοινωνιακά και cloud περιβάλλοντα.
Στόχοι της εργασίας
Ανάλυση και προεπεξεργασία δεδομένων CPU [και RAM.]
Ανάπτυξη και εκπαίδευση μοντέλων πρόβλεψης χρονοσειρών, όπως το LSTM, GRU και Transformers.
Πρόβλεψη χρήσης πόρων για: 1) short-term horizon (5 timesteps) και 2) long-term horizon (10 timesteps).
Αξιολόγηση των μοντέλων με τις μετρικές MSE, MAE και MAPE.
Σύγκριση τουλάχιστον 2 μοντέλων ως προς την ακρίβεια πρόβλεψης, το inference time και την υπολογιστική πολυπλοκότητα.
Εξαγωγή συμπερασμάτων σχετικά με την καταλληλότητα των μοντέλων σε πραγματικά συστήματα διαχείρισης πόρων.
