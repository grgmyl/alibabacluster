# ΕΡΓΑΣΙΑ 08:Πρόβλεψη Χρήσης Πόρων Στο Alibaba Cluster Dataset

## Περιγραφή

Η εργασία αυτή εξετάζει την πρόβλεψη της χρήσης CPU σε περιβάλλον cloud χρησιμοποιώντας δεδομένα από το Alibaba Cluster Dataset. Υλοποιούνται και συγκρίνονται μοντέλα βαθιάς μάθησης για πρόβλεψη χρονοσειρών με διαφορετικούς χρονικούς ορίζοντες.

## Περιεχόμενα Repository

### `preprocessing.py`

Περιέχει την προεπεξεργασία των αρχικών δεδομένων:

* καθαρισμό δεδομένων,
* επιλογή χαρακτηριστικών,
* κανονικοποίηση,
* δημιουργία του τελικού dataset που χρησιμοποιείται από τα μοντέλα.

### `lstmmodel`

Υλοποίηση του μοντέλου LSTM (Long Short-Term Memory) για πρόβλεψη χρήσης CPU. Περιλαμβάνει εκπαίδευση, αξιολόγηση και παραγωγή γραφημάτων αποτελεσμάτων.

### `grumodel`

Υλοποίηση του μοντέλου GRU (Gated Recurrent Unit). Εκτελεί πρόβλεψη πολλαπλών χρονικών βημάτων και υπολογίζει μετρικές όπως MSE, MAE και MAPE.

### `transformers`

Υλοποίηση μοντέλου Transformer για πρόβλεψη χρονοσειρών. Χρησιμοποιεί μηχανισμό attention για τη μοντελοποίηση χρονικών εξαρτήσεων.

### `parousiasi.pptx`

Παρουσίαση της εργασίας με τη μεθοδολογία, τα πειράματα και τα αποτελέσματα.

### `Αναφορά εργασίας`

Η τελική αναφορά της εργασίας με θεωρητικό υπόβαθρο, περιγραφή υλοποίησης, αποτελέσματα και συμπεράσματα.

### `ΣΧΕΤΙΚΗ ΒΙΒΛΙΟΓΡΑΦΙΑ`

Αρχεία και πηγές που χρησιμοποιήθηκαν για τη μελέτη και υλοποίηση της εργασίας.

## Στόχος

Στόχος της εργασίας είναι η σύγκριση των μοντέλων LSTM, GRU και Transformer ως προς:

* την ακρίβεια πρόβλεψης,
* το σφάλμα πρόβλεψης (MSE, MAE, MAPE),
* τον χρόνο εκτέλεσης,
* την καταλληλότητά τους για συστήματα διαχείρισης πόρων σε cloud περιβάλλοντα.
